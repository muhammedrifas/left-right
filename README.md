# Left-Right 🎮

A fast-paced, reaction-based mobile game built with Flutter. Test your reflexes by making split-second decisions against a dynamic timer, navigating through directional and color prompts, and surviving mind-bending mirror modes.

## ✨ Features

*   **Time-Attack Mechanics:** A dynamic countdown timer. Make correct choices quickly to add time back to the clock and keep the game alive.
*   **Color & Direction Prompts:** React to challenging prompts using both directions (Left, Right, Top, Bottom) and colors.
*   **Opposite Mode:** A challenging twist where directions are inverted (colors remain normal), signaled by subtle glitch/blur screen effects.
*   **Clean UI:** Distraction-free interface featuring a sleek timer and real-time score display.
